# lolsito

esta aplicacion funciona gracias a Dios todo poderoso, antes solo Dios y yo sabiamos como funcionaba, ahora solo lo sabe Dios

Total de horas gastadas (subir el contador): 12h

## que hace

guarda campeones del lol y los pasa a un xml

- elegir el tipo (mago, luchador, asesino, tirador, soporte, tanque)
- poner nombre, region, fecha, mana y descripcion
- la fecha y el mana salen al azar
- Nuevo: guarda el campeon en la lista
- Mostrar: escribes el nombre y sale todo
- Exportar e Importar: guardar y cargar el xml
- al cerrar pregunta si quieres salir

## como se usa

abrir en intellij con el jdk 8 y ejecutar Principal. las librerias estan en Libs
